# Проекты договоров по согласованным условиям

Для каждой новой `AgreementVersion` сервис создаёт отдельный неизменяемый `AgreementContract`.

Экземпляр содержит:

- версию шаблона;
- версию согласованных условий;
- задачи, график и стоимость каждого Выхода;
- общую стоимость помощи и сервисные сборы;
- комментарий к условиям;
- `termsHash` исходной версии условий;
- SHA-256 checksum сохранённого файла.

Файл хранится в persistent storage:

`/data/uploads/agreement-contracts/<requestId>/<agreementVersionId>/<contractId>.txt`

Каталог `/uploads` не публикуется. Просмотр метаданных выполняется через `GET /api/agreement-contracts/:id`, скачивание — через `GET /api/agreement-contracts/:id/download`. Доступ имеют только Заказчик и Помощник соответствующего чата, а также Суперадминистратор. Каждое скачивание записывается в `AuditLog`.

Изменение согласованных условий создаёт новую `AgreementVersion` и новый экземпляр проекта договора. Endpoint изменения существующего экземпляра отсутствует.

Документы Помощников также скачиваются только через защищённый endpoint `GET /api/performer-documents/:id/download`. Доступ разрешён владельцу документа и Суперадминистратору.
