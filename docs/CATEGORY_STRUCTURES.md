# Структуры категорий

## Назначение

Структура категорий определяет направления бытовой помощи, подкатегории, типовые задачи, ограничения и рекомендуемые ориентиры для конкретной территории. Это версионный справочник, а не плоский список.

Иерархия:

```text
Базовая структура РФ -> региональная структура -> городская структура
```

- Базовая структура РФ является безопасным шаблоном и создаётся bootstrap идемпотентно.
- Региональная структура уточняет шаблон для региона.
- Городская структура является рабочей для подключённого города.
- Active-структура не редактируется напрямую. Для изменений создаётся draft новой версии.
- Публикация draft архивирует предыдущую active-версию того же scope.
- Использованные версии и snapshot заявок физически не удаляются.

## Fallback

`getEffectiveCategoryStructure(cityId)` выбирает структуру в порядке:

1. active city: `local_ready`;
2. active region: `uses_region_fallback`;
3. active federal: `uses_federal_fallback`;
4. отсутствует: `missing_structure`.

Заказчик и Помощник получают категории effective-структуры без технического предупреждения. Администратор видит отдельную таблицу городов без локальной структуры и может создать draft или скачать предзаполненный шаблон.

## Заявки и Помощники

При создании или переклассификации заявки создаётся `RequestCategorySnapshot`. В JSON фиксируются версия и scope структуры, fallback, категория, подкатегория, типовая и дополнительная задачи, частота, исходный диапазон, точная ориентировочная сумма, breakdown, показанные ограничения, город и дата. Переименование справочника не меняет историю заявки. Формула описана в `docs/REQUEST_CALCULATOR.md`.

Помощник выбирает категории отдельно для города. `HelperCategoryPreference` хранит и `categoryId`, и стабильный `categorySlug`. Совпадающие заявки показываются выше, остальные не скрываются.

## Безопасность

- Управление, импорт, публикация и архивирование доступны только admin/superadmin.
- Manager может читать пользовательские категории и менять category snapshot незакрытой заявки, но не справочник.
- Импорт ограничен 5 МБ, принимает JSON/XLSX, валидирует связи, диапазоны и тексты, создаёт только draft.
- Ремонтные, технические и опасные работы не предлагаются.
- Медицинские процедуры запрещены; сервис не заменяет экстренные и профильные службы.
- Цены являются рекомендуемым ориентиром. Итоговая сумма согласуется в чате.

## Админка

Раздел `Справочники -> Структуры категорий` содержит обзор, структуры, города без локальной структуры, импорт/экспорт и версии. AuditLog фиксирует create-from-parent, import, export, publish, archive и переклассификацию заявки.
