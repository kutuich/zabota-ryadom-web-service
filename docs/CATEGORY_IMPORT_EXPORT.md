# Импорт и экспорт структур категорий

## Экспорт

Доступны Excel и JSON. Excel содержит листы:

1. Паспорт структуры.
2. Категории.
3. Типовые задачи.
4. Ограничения.
5. Рекомендуемые цены.
6. Инструкция.

Для города экспорт всегда формирует городской документ:

- при active city используется городская версия;
- без city используется active region и суффикс `_from_region`;
- без region используется федеральный шаблон и суффикс `_from_federal_template`.

Регион без active-структуры получает шаблон из РФ. Паспорт содержит target scope, идентификаторы региона/города, основу, версии и предупреждение.

## Импорт

1. Откройте `Импорт/экспорт`.
2. Выберите `.xlsx` или `.json` до 5 МБ.
3. Проверьте preview, ошибки и предупреждения.
4. Нажмите `Создать черновик`.
5. Проверьте категории, ограничения и рекомендуемые цены.

Диапазон из импортированной `CategoryPricingRule` используется как база ориентиров. Точная сумма для новой заявки рассчитывается по частоте и длительности согласно `docs/REQUEST_CALCULATOR.md`; итоговая сумма подтверждается в чате.
6. Опубликуйте draft отдельным действием.

Импорт никогда не перезаписывает опубликованную структуру и не публикует данные автоматически. Повтор одного payload блокируется по SHA-256 `importHash`.

## Валидация

- `slug` обязателен, уникален и имеет формат `lower-kebab-case`;
- `parentSlug` и ссылки на категории должны существовать;
- цены неотрицательны, `min <= max`;
- проверяются status, severity и boolean-поля;
- запрещённые публичные термины отклоняются;
- упоминание ремонтных, технических или опасных направлений выдаёт предупреждение;
- значения `true/false`, `да/нет`, `1/0` поддерживаются при чтении Excel.

JSON использует стабильные разделы `version`, `scope`, `passport`, `categories`, `taskTemplates`, `safetyRules`, `pricingRules`.
