# landing-public

Это очищенная публичная часть старой папки `Care servis`, подготовленная для будущего объединения с `web-service`.

Публиковать можно только эту папку. В неё перенесены статические страницы лендинга, стили, скрипты и изображения, которые нужны публичному сайту.

Старые PHP-разделы и служебные директории из исходного `Care servis` не использовать:

- `admin/`
- `api/`
- `includes/`
- `data/`
- `*.php`

Позже backend `web-service` будет отдавать эту папку на `/`. Сейчас routing backend/frontend, Vite base и Dockerfile не изменялись.
