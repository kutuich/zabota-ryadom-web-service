# landing-public

> Статус: ACTIVE COMPONENT DOCUMENT.

Статические публичные страницы, которые production backend отдаёт на `/`. React-приложение доступно на `/app`, API — на `/api`, legal routes — на `/legal/*`.

Старые PHP-разделы и служебные директории исходного сайта не используются. Публичные тексты должны соответствовать утверждённой продуктовой архитектуре в Notion, актуальной терминологии и ценовым правилам. Изменение landing не меняет backend pricing или workflow без отдельного решения.
