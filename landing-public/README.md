Статические публичные страницы, которые production backend отдаёт на `/`. React-приложение доступно на `/app`, API — на `/api`, legal routes — на `/legal/*`.

Старые PHP-разделы и служебные директории исходного сайта не используются. Публичные тексты должны соответствовать [source of truth](../ZABOTA_RYADOM_CURRENT_SOURCE_OF_TRUTH.md), актуальной терминологии и ценовым правилам. Изменение landing не меняет backend pricing или workflow без отдельного решения.
