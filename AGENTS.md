# AGENTS.md — обязательные правила проекта

## Перед работой

1. Откройте [`docs/DOCUMENTATION_INDEX.md`](docs/DOCUMENTATION_INDEX.md).
2. Прочитайте [`ZABOTA_RYADOM_CURRENT_SOURCE_OF_TRUTH.md`](ZABOTA_RYADOM_CURRENT_SOURCE_OF_TRUTH.md) и технический документ затрагиваемого домена.
3. Проверьте `git status --short` и фактические модели, endpoint и тесты. Локальная рабочая копия может быть новее GitHub.
4. Не выдавайте незавершённый функционал или technical draft за готовое продуктовое решение.

## Неподвижные правила

- Новая заявка использует четыре публичных направления и `selectedTasks[]`; legacy single-extra-task форму не возвращать.
- График всегда конечный. Один конкретный непересекающийся слот на дату равен одному визиту.
- Стоимость каждого визита рассчитывается отдельно; итог графика является суммой визитов, а не первой ценой, умноженной на их число.
- Сервисный сбор фиксирован: 50 ₽ с Заказчика и 50 ₽ с Помощника за каждый согласованный визит.
- Создание заявки и чат не списывают сбор. Списание происходит атомарно только после подтверждения одной версии условий обеими сторонами.
- Оплата помощи проходит напрямую между Заказчиком и Помощником. Внутренний баланс используется для сервисного сбора.
- Внутренний резерв является аналитическим показателем, а не депозитом, эскроу или банковской блокировкой.
- Обычные задачи не меняют live T-Bank, production env, опубликованные legal-документы или active-структуры категорий.

## Терминология UI

Использовать: Заказчик, Помощник, Подопечный, сервисный сбор, бытовая помощь, сопровождение, уход на дому без медицинских процедур, согласованный визит.

Не использовать публично: клиент, исполнитель, комиссия, работник, сотрудник, нанять, трудоустройство, медицинские услуги. Технические имена `client`, `performer`, `ClientRequest` допустимы в коде.

## Legal и адреса

Публичные legal-маршруты `/legal` и `/legal/*` работают без авторизации. Опубликованная версия документа не редактируется напрямую.

До перехода заявки в работу Помощник видит город и улицу. После перехода — город, улицу и дом. Квартира, подъезд, этаж, домофон и закрытый комментарий не попадают в публичный DTO или ссылку на Яндекс.Карты.

## Изменения и отчёт

- При изменении бизнес-решения обновите source of truth и [`docs/DECISIONS_LOG.md`](docs/DECISIONS_LOG.md).
- При изменении реализации обновите доменный документ и тесты; несовместимый snapshot получает новую schema version.
- Следуйте [`docs/CHANGE_MANAGEMENT.md`](docs/CHANGE_MANAGEMENT.md).
- В отчёте укажите изменённые файлы, миграции, документацию, команды и результаты, а также всё, что осталось незавершённым.
- Минимальные проверки: `npm run check`, `npm test`, `npm run build`, `git diff --check`. Для UI дополнительно запускается доступный visual audit.
