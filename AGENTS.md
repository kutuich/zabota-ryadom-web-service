# AGENTS.md — Забота Рядом

## Проект
«Забота Рядом» — локальный сервис помощи для семьи, дома и близких.

Сервис не является:
- медицинской организацией;
- социальной службой;
- патронажной службой;
- государственным учреждением;
- работодателем Помощников.

Сервис не выполняет медицинские процедуры.

## Термины UI
В пользовательском интерфейсе и новых документах использовать:
- Заказчик;
- Помощник;
- Подопечный;
- сервисный сбор;
- бытовая помощь;
- сопровождение;
- уход на дому без медицинских процедур.

В коде технические роли client / performer / admin можно оставить.

Не использовать в UI:
- клиент;
- исполнитель;
- комиссия
- работник
- сотрудник
- нанять
- трудоустройство

Главный источник требований: `ZABOTA_RYADOM_CURRENT_SOURCE_OF_TRUTH.md`.

## Проверки перед завершением задачи
После изменений запускать:
npm run check
npm test
npm run build

Если задача влияет на UI:
npm run visual:audit

## Формат работы
Для сложных задач сначала:
1. Найти релевантные файлы.
2. Кратко описать, где находится логика.
3. Только потом менять код.

Не делать большие архитектурные изменения без явного указания.

## Legal-модуль
Публичные маршруты legal должны работать без авторизации:
- /legal
- /legal/privacy
- /legal/personal-data-consent
- /legal/customer-agreement
- /legal/helper-terms
- /legal/service-notifications-consent
- /legal/marketing-notifications-consent
- /legal/helper-documents-consent
- /legal/service-rules

Админский маршрут:
- /admin/legal

Если visual audit говорит, что маршрут открыл / вместо /legal, задача НЕ выполнена.

## Адреса и Яндекс.Карты
Пока не подключать API Яндекс.Карт.
Использовать только внешние ссылки:
https://yandex.ru/maps/?text=...

До перехода заявки в работу помощник видит:
город + улицу.

После перехода заявки в работу помощник видит:
город + улицу + дом.

Квартира, подъезд, этаж, домофон и комментарий не попадают в ссылку на Яндекс.Карты.

## Правило завершения
В отчёте всегда указывать:
- какие файлы изменены;
- какие команды запущены;
- результат команд;
- что осталось не сделано.
